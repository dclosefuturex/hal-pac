# Original asset provenance

All game assets were authored specifically for Prism Rally as source code in this workspace.

- Racer portraits: inline pixel-grid SVG generation in src/main.js.
- Kart/animal silhouettes, trees/palms/cacti/crystals, item boxes, projectiles, track textures, horizon art and animation: Canvas primitives in src/render.js.
- Twelve fictional layouts and eight fictional characters: src/data.js.
- Music: original 118 BPM sixteen-step melody over four chord roots in src/audio.js.
- Engine, skids, impacts, boost, pickups, countdown, jump, landing, recovery and finish: local oscillator synthesis in src/audio.js.
- Interface: system fonts and original CSS. Unicode symbols use the browser's installed font.

There are no downloaded images, sampled sounds, third-party fonts, traced layouts, extracted assets, or runtime generation services. All listed assets are covered by LICENSE.
